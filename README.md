# RUSSIA: LIFE & BEYOND — The Living Atlas

A browser game set on the real map of Russia. Live a daily life, travel across the country, and unlock landmarks with real history and nature facts.

**Play:** https://pritidipadas.github.io/RUSSIA-THE-LIVING-ATLAS/

## Features
- Whole-country OpenStreetMap map (zoom from country to street level)
- Life simulation: energy, hunger, thirst, hygiene, mood, bladder, pet care
- Context actions from OSM data: swim, hike, run, camp, sleep, shop, eat, work, adopt a pet, change clothes
- Travel by walking, running, bike, car, train or boat (simulated journeys with encounters)
- 12 discoverable landmarks (Baikal, Elbrus, Kremlin, Kamchatka, Ladoga, Volga, Trans-Siberian…) with live Wikipedia/Wikidata info
- Day/night, seasons, real weather, rain/snow/clouds, animated character scene
- Missions, collectibles, real wildlife records (GBIF)

## Data sources
Map data © OpenStreetMap contributors (served by OpenFreeMap) · MapLibre GL JS · Open-Meteo (weather, Copernicus DEM elevation) · Wikipedia & Wikidata · UNESCO · GBIF · OSRM
